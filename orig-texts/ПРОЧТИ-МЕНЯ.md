# orig-texts — чистый текст страниц для «Оригинальных текстов» Яндекса

В папке лежат текстовые файлы: **только видимый текст страницы**, без HTML-тегов и мета-тегов —
готово для вставки в Яндекс.Вебмастер → «Индексирование» → «Оригинальные тексты».

Что в файле: заголовок страницы, абзацы, формулы, списки, таблицы, вопросы и ответы.
Чего нет: разметки, комментариев панели, меню и крошек, формы отзыва, рекламных слотов,
блока «Смотрите также», строки «Обновлено» и дисклеймера.

## Как собрать текст для любой страницы

```
php _game-test\orig-text.php /blog/otpusknye/     один адрес → orig-texts/blog-otpusknye.txt
php _game-test\orig-text.php --all                все страницы, где есть текст
php _game-test\orig-text.php --all --min=1500     только страницы с текстом от 1500 знаков
```

Имя файла — адрес страницы без слэшей: `/blog/otpusknye/` → `blog-otpusknye.txt`,
`/calculators/finance/vat/` → `calculators-finance-vat.txt`, главная → `home.txt`.

## Что стоит знать

- текст берётся из размеченных участков страницы (`EDIT:seo` — основной текст, `EDIT:faq` — вопросы),
  поэтому в файл не попадает служебная обвязка сайта;
- для «Оригинальных текстов» Яндекс просит текст конкретной страницы — берите файл, совпадающий с её адресом;
- файлы перезаписываются при повторном запуске: правьте страницу на сайте, потом обновите файл командой.
