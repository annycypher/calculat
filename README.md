# CalcDoc — онлайн-калькуляторы и генераторы документов

Бесплатный набор онлайн-инструментов, который работает **прямо в браузере, без бэкенда и базы данных**.
Рассчитан на продвижение органическим SEO (каждый инструмент — отдельная статичная страница с мета-данными),
мonetization через баннерные блоки и партнёрские ссылки, а также на установку как **PWA (кнопка «Скачать на рабочий стол»)**.

## Стек

- **HTML + CSS + ванильный JavaScript (ES-модули)** — без сборщика и без Node.js.
- **PWA**: `manifest.webmanifest` — установка на рабочий стол/телефон.
- **PDF-документы** — через встроенный «Печать → Сохранить как PDF» (без внешних библиотек).
- **Хостинг** — любой статический (Cloudflare Pages / GitHub Pages / Vercel), бесплатно.

## Структура

```
calc_docs/
├─ index.html                     # Главная: сетка калькуляторов и генераторов + SEO-текст
├─ styles.css                     # Общий адаптивный визуал (светлая/тёмная тема)
├─ manifest.webmanifest           # Манифест PWA (установка на рабочий стол)
├─ robots.txt                     # Для поисковых систем
├─ sitemap.xml                    # Карта сайта для SEO
├─ icons/icon.svg                 # Иконка приложения
├─ js/
│  ├─ ui.js                       # Тема, кнопка «Установить»
│  ├─ calc-tax-freelancer.js      # Калькулятор налога (НПД)
│  └─ gen-resume.js               # Генератор резюме → PDF
├─ calculators/
│  └─ tax-freelancer.html         # Страница калькулятора налога
└─ generators/
   └─ resume.html                 # Страница генератора резюме
```

## Локальный запуск (превью)

ES-модули требуют, чтобы сайт отдавался через HTTP (не `file://`).
Простейший способ (Python уже установлен):

```powershell
cd calc_docs
python -m http.server 8000
```

Откройте `http://127.0.0.1:8000`. Или используйте расширение **Live Server** в VS Code.

## Как добавить новый инструмент (расширяемость)

1. Создайте страницу `calculators/<slug>.html` (или `generators/<slug>.html`) — скопируйте шаблон из любой существующей,
   замените заголовки, `meta description`, `canonical` и `application/ld+json`.
2. Подключите при необходимости новый JS-файл в `<script type="module" src="/js/<slug>.js">`.
3. Добавьте карточку на главную (`index.html`, секции `#tools` или `#files`).
4. Добавьте URL в `sitemap.xml`.
5. **SEO-статья под калькулятором — обязательна.** Каждый новый инструмент выходит сразу с текстовым
   SEO-блоком в `<div class="container section">` внутри `<main>`: заголовок `<h2>`, 5–10 разделов
   (как считать, формула, пример с числами, что влияет на результат, ограничения, ссылки на связанные
   инструменты) и FAQ-аккордеон на нативных `<details class="seo-faq">` — без JavaScript, чтобы вопросы
   были видны поисковику. Стили общие — `/seo-article.css` (классы `.seo-*`), локальные `<style>` в
   страницу не добавляем. Пример готового блока — `calculators/finance/credit/index.html`.
6. **Разметка FAQPage собирается из видимого текста.** Готовые статьи лежат в `_game-test\seo\<slug>.html`,
   метатеги — в `_game-test\seo\meta.json`; `_game-test\apply-seo-blocks.ps1` вставляет блок, подключает
   `/seo-article.css` и генерирует `<script type="application/ld+json">` с `FAQPage` из вопросов и ответов
   страницы — поэтому разметка не может разойтись с текстом. После вставки запустите
   `_game-test\check-seo-pages.ps1` (баланс тегов, JSON-LD, совпадение FAQ, длины метатегов, уникальность
   абзацев) и залейте изменённое: `sweb-migration\upload-file.ps1 -ListFile <список>`.

## Монетизация

- **Баннеры** — блоки `<div class="ad-slot">` на страницах (на главной и рядом с инструментом).
  Замените содержимое на код AdSense/другой сети или партнёрскую ссылку.
- **Партнёрские ссылки** — логично встраиваются в калькуляторы (ипотека → банки, документы → юрсервисы).
- **PRO-версия** — возможное развитие (отключение рекламы + премиум-функции).

## SEO

- Каждый инструмент — отдельный статический HTML с `title`, `description`, `canonical`, `robots`, Open Graph
  и `JSON-LD` (`SoftwareApplication`). Поисковик видит весь контент без JS.
- `sitemap.xml` + `robots.txt`.
- Домен: `https://calc-doc.ru/` (указан в `canonical`, `sitemap.xml`, `robots.txt` и мета-тегах).

## Деплой (бесплатно)

- **Cloudflare Pages**: подключите репозиторий → Build command: пусто (или `none`) → Build output: `/` (корень).
- **GitHub Pages**: включите Pages (ветка `main`, `/root`). Проект статический, сборка не нужна.
- **Vercel**: подключите репозиторий → Framework: `Other` → Output: `/`.

## Важные примечания

- Для полной установки PWA на мобильных браузерам нужны PNG-иконки 192×192 и 512×512.
  Сейчас используется SVG — добавьте PNG, когда будете готовы.
- Данные пользователей не отправляются на сервер; сохранение — только в `localStorage` браузера.
