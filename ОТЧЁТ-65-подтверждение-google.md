# Отчёт 65. Подтверждение права собственности в Google (файл google4975606b16bf6ff1.html)

Дата: 24.09.2026. Задача владельца: подтвердить право на сайт в Google Search Console файлом.

## Что сделано

1. **Создан файл подтверждения** `google4975606b16bf6ff1.html` в корне сайта с ровно таким содержимым:

   ```
   google-site-verification: google4975606b16bf6ff1.html
   ```

2. Файл записан **UTF-8 без BOM** (54 байта: строка + перевод строки). Это важно: BOM в начале файла
   ломает проверку — на файле Яндекса мы на это уже наступали, поэтому проверил первые байты отдельно
   (файл начинается на `google-`, никаких служебных символов).
3. Файл залит на хостинг в корень сайта (`/public_html/google4975606b16bf6ff1.html`).

## Чем проверено

| Проверка | Результат |
|---|---|
| Живой адрес | https://calc-doc.ru/google4975606b16bf6ff1.html → **HTTP 200** |
| Размер | 54 байта (как у локального) |
| Содержимое | точно `google-site-verification: google4975606b16bf6ff1.html` |
| SHA-256 живой копии | **совпадает** с локальным файлом |
| BOM | нет (первый байт — `g`) |
| robots.txt | `Allow: /`; закрыты только `/search.html`, `/offline.html`, `/api/` — файл подтверждения не задет |

## Что сделать в Google Search Console (полминуты)

1. Откройте https://search.google.com/search-console → **«Добавить ресурс»** → выберите
   **«Префикс URL»** и вставьте `https://calc-doc.ru/`.
2. В окне подтверждения выберите способ **«Файл HTML»** — Google покажет то же имя файла
   (`google4975606b16bf6ff1.html`). Ничего скачивать не нужно: файл уже лежит на сайте.
3. Нажмите **«Подтвердить»** — проверка должна пройти сразу.

**Файл удалять нельзя**: Google периодически перепроверяет подтверждение. Он ничего не весит (54 байта)
и в выдаче не мешает.

Дальше, когда доступ появится, полезно сразу отправить карту сайта: в Search Console →
«Файлы Sitemap» → добавить `https://calc-doc.ru/sitemap.xml` (там сейчас 93 адреса, включая глоссарий).
