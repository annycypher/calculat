# Отчёт 67. Проверка robots.txt

Дата: 24.09.2026. Задача владельца: проверить robots.txt — рабочий вариант должен содержать
`Allow: /`, `Disallow: /api/` и Sitemap, и не должен содержать полный запрет `Disallow: /`.

## Результат проверки — всё как надо

Живой файл https://calc-doc.ru/robots.txt (полное содержимое):

```
# Открытый сайт CalcDoc (режим переноса снят 23.09.2026 по команде владельца).
# До этого стояли «Disallow: /» и noindex на страницах — сайт не попадал в поиск.
# Директива Host в Яндекс.Вебмастере не используется с 2018 года, поэтому её нет.
# Карта сайта обновлена 24.09.2026: /sitemap.xml (93 адреса, дата правки страниц).

User-agent: *
Allow: /
Disallow: /search.html
Disallow: /offline.html

# Служебный обмен данными страниц (JSON, отдаёт только счётчики страниц) — обход не нужен
Disallow: /api/

# Метки систем аналитики не создают отдельных адресов
Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term&yclid&gclid&fbclid

Sitemap: https://calc-doc.ru/sitemap.xml
```

| Проверка | Результат |
|---|---|
| `User-agent: *` есть | да |
| `Allow: /` есть | **да** |
| `Disallow: /api/` есть | **да** |
| `Sitemap:` указан | **да** — `https://calc-doc.ru/sitemap.xml` |
| Полный запрет `Disallow: /` | **нет** (строчными: только `/search.html`, `/offline.html`, `/api/`) |
| Живая копия и локальная | совпадают по SHA-256 |
| Дополнительно | `Clean-param` для utm-меток — рекламные метки не создают «лишних» адресов |

Что закрыто и почему: `/search.html` (страница поиска — дубли), `/offline.html` (заглушка PWA)
и `/api/` (служебный обмен, отдаёт только счётчики). Всё остальное открыто: разделы, инструменты,
статьи, глоссарий и файлы подтверждения поисковиков — они не закрыты и видны роботам.

## Что поправил по ходу проверки

В комментарии файла было написано «Карта сайта обновлена 24.09.2026: /sitemap.xml (**82 адреса**)» —
это устарело: после глоссария и десяти терминов в карте **93 адреса**. Комментарий обновлён,
файл залит заново, живая копия побайтово совпала с локальной.

## Куда смотреть глазами

- Файл: https://calc-doc.ru/robots.txt
- Карта, на которую он ссылается: https://calc-doc.ru/sitemap.xml (93 адреса)
- Проверка в панели: щиток на дашборде следит за robots.txt сам и показывает плашку, если что-то не так —
  https://calc-doc.ru/_sysudh2xsye/dashboard.php (для гостя перебрасывает на вход, каталог `/_sysudh2xsye/`
  отдаёт 403 — это правильное поведение; локальная папка проекта называется `admin-panel-x7k2`, на сервере
  её нет, поэтому `calc-doc.ru/admin-panel-x7k2/` отвечает 404 и это нормально).
