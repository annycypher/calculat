# Перенос на хостинг (фаза 14) — инструкция для владельца

Этот файл готовит перенос и приёмку. Деплой делает ВЛАДЕЛЕЦ по этим шагам, панель и сайт
до команды «ОТКРЫВАЕМ САЙТ» живут в **режиме приватности**.

## 1. Предполёт (сделано локально, проверять не нужно)

- [x] `.htaccess` стоят в закрытых папках: `content/`, `content/logs/`, `content/security/`,
      `backups/`, `admin-panel-x7k2/inc/`.
- [x] Загрузки защищены: `media/uploads/.htaccess` запрещает выполнять скрипты из папки картинок
      и закрывает листинг (`Options -Indexes`).
- [x] Секретов в репозитории нет: `content/users.json`, `settings.json`, `articles.json`,
      `reviews.json`, `reminders.json`, `catalog.json`, `content/security/*`, `content/logs/*`,
      `media/uploads/*` — в `.gitignore`; в git из служебного лежат только сами `.htaccess`.
- [x] Все тесты зелёные, все фазы 1–13 закрыты (см. PROGRESS.md).

## 2. Что заливать на хостинг

Заливаем всё, кроме служебного и личного:

- **Не заливать:** `.git/`, `_game-test/`, `_archive/`, `_backup/`, `backups/`,
  `sweb-migration/`, `node_modules/` (если появится), `shots/`.
- **Заливать:** страницы сайта, `js/`, `libs/`, `icons/`, `img/`, `fonts/`, `media/`, `api/`,
  `admin-panel-x7k2/`, `content/` (пустой, с `.htaccess` — данные панель создаст сама),
  `robots.txt`, `sitemap.xml`, `rss.xml`, `service-worker.js`, `offline.html`, `.htaccess`-файлы.

## 3. Режим приватности (до «ОТКРЫВАЕМ САЙТ»)

1. **Basic auth на весь сайт** (в панели хостинга: «Защита каталога паролем», логин/пароль — только у вас).
2. **`robots.txt`: `Disallow: /`** и строка про панель (панель умеет сама — раздел «Безопасность»).
3. **`noindex`**: в шаблоне страниц заменить `index, follow` на `noindex, nofollow`
   (после открытия вернуть обратно — это же место, где стоит canonical).
4. **Ничего не подключать публично:** Метрика, Вебмастер/GSC, РСЯ, соцсети, внешние ссылки — до открытия.
5. Панель проверить по секретному адресу: вход, смена пароля, «Красивые адреса» не нужны.

## 4. Приёмка на живом сервере

- [ ] Сайт открывается по техадресу, панель — по своему адресу, вход работает.
- [ ] `robots.txt` отдаётся с `Disallow: /`; страницы содержат `noindex`.
- [ ] `content/`, `backups/`, `inc/` закрыты (прямой заход даёт 403/404, не отдаёт файлы).
- [ ] Загрузки: ссылка на картинку из `media/uploads/` работает, а `.php` оттуда — нет.
- [ ] Панель: «Копия сейчас» работает, появился свежий архив; «Настройки» сохраняются.
- [ ] Локальный калькулятор считает; печать даёт белый лист с результатом; PNG-карточка скачивается.
- [ ] Офлайн-режим на устройстве (выключить сеть, открыть калькулятор) — проверка глазами.
- [ ] PageSpeed ≥85 на главной и на калькуляторе — проверка глазами.
