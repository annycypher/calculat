## 3. Важный вывод для следующих шагов фазы

**Хостинг работает на PHP 7.1.33.** В фазах P3–P7 код писать совместимо с 7.1: без типизированных свойств,
без `fn()`, `?->`, `match`, `readonly`, `str_contains`, без запятых в конце вызовов функций.
Это уже внесено в тесты: у меня есть быстрый скан на такие конструкции — применю перед каждой заливкой.

## 4. Побочная находка (не из этого шага)

В серверном журнале постоянно (на каждый запрос панели) появляется:
`PHP Notice: Array to string conversion in .../inc/auth.php on line 41`. Ошибка не моя и была раньше,
на работу не влияет, но журнал засоряет. Могу починить отдельным маленьким шагом по вашему слову.
