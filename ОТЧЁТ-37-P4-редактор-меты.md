# ОТЧЁТ-37. Фаза P4 — редактор меты для всех страниц

Дата: 23.09.2026. По ТЗ `PROMPT-PANEL-DEVELOPMENT.md` (шаг 4.1). Развёрнуто и проверено на живом хостинге.

## 1. Что сделано

| Файл | Что добавлено |
|---|---|
| **`inc/meta.php`** (новый) | библиотека: `meta_pages()` (список страниц из карты сайта — 81), `meta_read()` (title, description, H1, ключ, lastmod), `meta_dupes()` (поиск дублей с нормализацией регистра и «ё»), `meta_save()` (**точечная** правка меты), `meta_sitemap_touch()` (lastmod → сегодня) |
| **`meta.php`** (новая страница) | выбор любой страницы из 81; поля **title** (счётчик 45–60), **description** (140–160), **H1**, **ключ SEO-центра**; живые подсказки и рамки (жёлтая вне нормы, красная при дубле); **живой предпросмотр сниппета Яндекса** (синий заголовок, зелёный адрес, серый текст); кнопка «Сохранить мету»; ссылка «Переобход в Вебмастере»; ссылка в «Публикацию» |
| `inc/ui.php` | пункт меню **«Мета-теги»** переведён из «не готово» в готовый (`ready: true`) |

**Как сохраняется правка (это главное для безопасности):** файл читается целиком, заменяются **только** фрагменты
title, description и текст H1; остальные байты остаются как были (разметка, счётчик Метрики, переводы строк).
Если менять нечего — файл вообще не перезаписывается. После сохранения автоматически обновляется `lastmod`
страницы в `sitemap.xml`, а сам файл попадает в **список публикации** — то есть на живом сайте правка появится
только после нажатия кнопки «Опубликовать» (как и требует фазa P2).

Ключевое слово сохраняется в SEO-центр (`content/seo.json`) — это не мета-тег keywords (поисковики его
не учитывают), а ключ, по которому SEO-центр считает плотность и ставит оценку.

## 3. Как этим пользоваться владельцу

1. **Контент → Мета-теги** → выбрать страницу из списка → видно текущие title, description, H1 и ключ.
2. Поправить поля: счётчики и цвет рамки сразу покажут, в норме ли длина; предпросмотр покажет, как это
   будет выглядеть в поиске; при совпадении с другой страницей появится красное предупреждение о дубле.
3. **Сохранить мету** → «файл добавлен в список публикации» → перейти в **«Публикация»** и нажать
   «📤 Опубликовать изменения», чтобы правка ушла на живой сайт.
4. Для ускорения переобхода — кнопка «Переобход в Вебмастере» (открывается нужный раздел; полная
   автоматизация требует токена Вебмастера, его у панели нет).
