# ОТЧЁТ-33. Фаза P2, шаг 2.3 — FTP-реквизиты в «Настройках»

Дата: 23.09.2026. По ТЗ `PROMPT-PANEL-DEVELOPMENT.md` (шаг 2.3: «владелец вносит FTP-данные через панель, не в чат»).
Развёрнуто и проверено на живом.

## 1. Что сделано (один файл — `settings.php`)

Новая карточка **«Публикация на хостинг (FTP)»** в разделе «Настройки»:

| Элемент | Что делает |
|---|---|
| Поля: FTP-сервер, порт, логин, пароль, папка сайта | владелец вводит данные из панели SpaceWeb («FTP-доступы») |
| Кнопка **«Сохранить FTP-доступ»** | пишет реквизиты в `content/secrets.json` (снаружи закрыт), в журнал панели пароль **не** попадает |
| Кнопка **«Проверить связь»** | подключается к хостингу и проверяет папку сайта — **ничего не заливая** |
| Ссылка «К разделу “Публикация”» | сразу перейти к кнопке публикации |
| Строка состояния | «Сейчас не заполнено: …» — видно, чего не хватает |

Мелочи, важные для удобства: **пустое поле пароля означает «не менять сохранённый»**, поэтому владельцу
не нужно вводить пароль каждый раз; пароль никогда не выводится на страницу (в поле — только подсказка
«пароль сохранён»); менять реквизиты может только администратор (у редактора кнопки выключены).

## 3. Что теперь может владелец

1. Открыть **Настройки → Публикация на хостинг (FTP)**, ввести адрес, порт, логин, пароль и папку сайта
   (данные — из панели SpaceWeb), нажать «Сохранить FTP-доступ», затем «Проверить связь».
2. Дальше работать в разделе **«Публикация»**: там список правок и кнопка «📤 Опубликовать изменения».
