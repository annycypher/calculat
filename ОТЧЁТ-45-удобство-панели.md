# Отчёт: удобство панели — картинки статьи, заливка, место после сохранения (24.09.2026)

Замечания владельца: (1) при редактировании статьи непонятно, куда вставлять картинки, какие размеры и вес
нужны и где они покажутся на сайте; (2) хочется заливать сразу на хостинг; (3) после сохранения страница
кидает в начало — надо оставаться там, где правил. Ниже — что уже сделано и варианты, что делать дальше.

## Сделано сейчас (залито на хостинг)

| Что | Было | Стало |
|---|---|---|
| Картинка статьи | поле называлось «Картинка для соцсетей (og:image)», про размеры и место показа ничего | «**Обложка статьи — карточка на /blog/ и превью в соцсетях**» + два пояснения: где видно (карточка на `/blog/`, превью в соцсетях и мессенджерах, разметка для поисковиков, **внутри статьи обложка не показывается**) и какую брать (1200×630, 16:9, до 200 КБ, JPG/WebP; панель сожмёт до 1920 и сделает копии 480/768/1200) |
| Картинка внутри текста | поля «имя файла» и «alt» без пояснений | добавлены пояснения: картинка встаёт в тексте по центру, ровно где стоит блок; подписи под картинкой нет — текст для незрячих и поисковиков берётся из «alt»; брать ширину от 1200 точек, до 200 КБ, копии 480/768/1200 делает панель |
| Заливка на хостинг | только через раздел «Публикация» (список изменённых файлов) | в редакторе статьи кнопка «**Залить на хостинг**» — отправляет файл этой статьи на сервер тем же движком `ftpDeploy()`, с подтверждением; при ошибке файл остаётся в списке публикации |
| Место после сохранения | панель после любого сохранения перезагружала страницу и владельца кидало в начало | панель запоминает позицию прокрутки и возвращает на неё после сохранения. Работает **на всех экранах панели**, не только в статьях |

**Как это сделано** (для истории): место прокрутки хранится в `sessionStorage` и восстанавливается, когда
на странице есть сообщение о сохранении (каркас панели ставит `data-keep-scroll="1"`) — то есть только
после сохранения, а не при обычном заходе. Кнопка заливки — операция `deploy_now` в `articles.php`
(переиспользован `inc/deploy.php`, никакого второго механизма заливки).

**Проверки:** `php -l` на изменённых файлах — чисто; `_game-test/check-panel-deploy.php` — реквизиты FTP
заполнены, связь с хостингом есть, папка сайта доступна (проверка в безопасном режиме `dry_run`,
лог `shots/_panel-deploy-check.log`); заливка панели `upload-panel.ps1` — 2 файла из 2,
обратная сверка SHA-256 — 2/2.

**Что проверить владельцу глазами** (панель → «Контент» → «Статьи» → открыть любую):
1. под полем обложки и у блока «Картинка из медиа-файлов» появились пояснения про размер, вес и место показа;
2. при правке блока и нажатии «Сохранить черновик» страница остаётся на том же месте (не прыгает в начало);
3. у опубликованной статьи рядом с «Опубликовать правки…» есть кнопка «Залить на хостинг» — она отправит
   файл статьи на сервер одной кнопкой.

## Варианты улучшений (выбрать, что делать дальше)

### 1. Картинки — самое частое место спотыкания
1. **Загружать картинку прямо из блока статьи** (сейчас: «Медиа-файлы» → загрузить → вернуться → выбрать). Даёт один шаг вместо трёх.
2. **Кнопка «Подготовить копии» в редакторе**: сейчас, если у картинки нет копий 480/768/1200, панель отправляет в «Медиа-файлы». Могу поставить кнопку прямо рядом с предупреждением.
3. **Предпросмотр карточки**: показывать миниатюру карточки статьи так, как она будет выглядеть на `/blog/` (обложка + заголовок + описание) — сразу видно, хорошо ли смотрится картинка.
4. **Подпись под картинкой** (`<figcaption>`): сейчас есть только alt. Это правка шаблона статьи + CSS — сделаю, если нужно подписывать иллюстрации.
5. Автоматически подставлять alt из названия файла и предупреждать, если он пустой (проверка уже есть).

### 2. Публикация
6. **Одна кнопка «Сохранить и залить»** — сохраняет черновик и сразу отправляет файл на хостинг (сейчас два шага).
7. **Счётчик «в списке публикации: N» в шапке** + кнопка «Опубликовать всё» — чтобы не забывать заливать правки.
8. Такой же кнопки «Залить на хостинг» в разделе «Текст страниц» (для правок текста страниц).

### 3. Работа с длинной статьёй
9. **Липкая панель кнопок** «Сохранить / Предпросмотр / Залить» — чтобы не прокручивать 20 блоков вверх.
10. **Оглавление блоков справа** (список с якорями) — переход к нужному блоку одним кликом.
11. **Автосохранение раз в минуту** с плашкой «сохранено 12:41» и напоминанием при попытке закрыть страницу с несохранёнными правками.
12. **Ctrl+S = сохранить** в редакторе.

### 4. Диагностика (для вас и для меня)
13. **Страница «Проверка сайта»**: картинки без alt, картинки без файла и копий, страницы без описания, битые внутренние ссылки, файлы, забытые в списке публикации. Часть этих проверок уже есть по местам — собрал бы в один отчёт с обходами.

Что предлагаю по порядку: **1 → 9 → 6 → 7** (самое частое и самое дешёвое), остальное — по желанию.
