АВТОЗАЛИВКА НА ХОСТИНГ (кнопка «Опубликовать»)═══════════════════════════════════════2.1. inc/deploy.php: функция ftpDeploy($changedFiles): - Читает FTP-данные из secrets.json (host, user, pass) - Подключается по FTP к SpaceWeb - Загружает каждый изменённый файл в соответствующую папку на хостинге - Логирует результат каждого файла - При ошибке — конкретное сообщение (не удалось подключиться, нет прав на папку, файл не найден)2.2. В панели: кнопка «📤 Опубликовать изменения» — показывает список изменённых файлов + кнопка «Подтвердить» + результат (успешно/ошибка по каждому файлу)2.3. Настройки FTP в секретах: host, user, pass (владелец вносит через панель, не в чат)2.4. Тест: внести правку в файл → нажать «Опубликовать» → проверить на живом сайте → откат → проверить, что вернулось2.5. Инструкция владельцу: как работает публикация, что делать при ошибке FTP, как проверить результат на живом сайте.→ Отчёт → «ДАЛЕЕ».

Дашборд: карточка «📊 Трафик» с табами: «Метрика» (посетители, визиты, источники) | «Свой счётчик» (просмотры, топ-страницы)3.3. Отчёт «Трафик за неделю» — сравнение недели с предыдущей, динамика, источники3.4. Экспорт: кнопка «Выгрузить CSV» (для владельца — сохранить историю трафика)→ Отчёт → «ДАЛЕЕ».
