Шрифты для calc-doc.ru (самохостинг, без Google Fonts).

Семейства: Unbounded 600, Manrope 400, Manrope 600.
Источник: Google Fonts. Лицензия: SIL Open Font License 1.1
(свободно, включая коммерческое использование; текст лицензии — https://openfontlicense.org).

Наборы (по 3 на каждое начертание, каждый файл < 20,5 КБ):
  <семейство>-<вес>-cyr.woff2 — кириллица + знак номера № (U+0400-045F, U+0490-0491, U+04B0-04B1, U+2116)
  <семейство>-<вес>-lat.woff2 — латиница + пунктуация (U+0020-007E, U+00A0-00FF, U+2013-2014, U+2018-2019, U+201C-201D, U+2026)
  <семейство>-<вес>-rub.woff2 — только знак рубля ₽ (U+20BD)

Почему так: на этом хостинге Cloudflare обрывает прямые ответы объёмом больше ~24,7 КБ,
поэтому каждый файл держим заметно ниже лимита (₽ вынесен отдельно, т.к. в исходных
наборах Google он лежит в крупном latin-ext — 49,5 КБ).

Подключение: fonts.css (содержит @font-face с unicode-range).
Пересборка: pyftsubset из fonttools (см. историю задач) или
скачать заново с https://fonts.googleapis.com/css2?family=Manrope:wght@400;600&family=Unbounded:wght@600
