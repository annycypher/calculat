# Запрос хостингу: включить HTTP/2 для calc-doc.ru

**Кому:** техническая поддержка хостинга (sweb / 77.222.61.245)
**Тема:** Включить HTTP/2 (и, если возможно, HTTP/3) для домена calc-doc.ru

---

## Текст запроса (можно отправлять как есть)

Здравствуйте!

Прошу включить **HTTP/2** для нашего сайта **calc-doc.ru** (тариф — виртуальный хостинг, сайт в каталоге `/public_html`).

Как проверить сейчас: ответы приходят по HTTP/1.1.

```
$ curl -sI https://calc-doc.ru/ | head -1
HTTP/1.1 200 OK
Server: nginx/1.31.3
```

Сайт отдаёт много мелких файлов (шрифты `.woff2`, иконки, CSS, JS-бандлы, картинки), поэтому на мобильной сети HTTP/1.1 ограничивает параллелизм и загрузка страницы получается дольше, чем могла бы. HTTP/2 убирает это ограничение без каких-либо изменений на нашей стороне.

Что просим:
1. включить HTTP/2 для домена `calc-doc.ru` (и для `www`, если он обслуживается тем же конфигом);
2. если это делается автоматически при включении SSL — просто подтвердите, что включено;
3. если у вас есть возможность — включить также HTTP/3 (QUIC), но это не обязательно.

Проверять будем сами: `curl -sI --http2 https://calc-doc.ru/` должен показать `HTTP/2 200`, в ответе появится заголовок `alt-svc` (для HTTP/3).

Наших изменений в конфигурации сайта не требуется: `.htaccess` при этом остаётся как есть, сжатие gzip уже включено и работает.

Спасибо!

---

## Что это даст (без преувеличений)

- **Плюс:** много мелких файлов перестанут стоять в очереди (один TCP-канал вместо шести-восьми), меньше задержек на TLS-рукопожатиях, чуть быстрее первый экран и догрузка картинок/шрифтов.
- **Ожидаемый эффект по цифрам:** обычно 5–15 % на первом экране в мобильной сети; на TBT (тяжесть главного потока) не влияет вовсе — это про сеть, а не про процессор.
- **Риск для сайта:** нулевой — это серверная настройка, ни файлы сайта, ни `.htaccess` не меняются.

## Как проверить после включения

```powershell
# версия протокола
curl.exe -sI https://calc-doc.ru/ | Select-String '^HTTP/'
# ожидаем: HTTP/2 200

# признак HTTP/3 (если включат)
curl.exe -sI https://calc-doc.ru/ | Select-String 'alt-svc'
# ожидаем: alt-svc: h3=":443"; ma=86400
```

Дополнительно после включения имеет смысл повторить замер главной:

```powershell
php -S 127.0.0.1:8099            # из папки calc_docs, в отдельном окне
powershell -File _game-test\cdp-metrics-repeat.ps1 -Url 'https://calc-doc.ru/' -Repeat 3
```

## Если ответят «нельзя»

Тогда единственный оставшийся рычаг по скорости — сокращать число и вес файлов:
1. часть иконок собрать в SVG-спрайт (одним запросом вместо десятков);
2. убрать из выдачи неиспользуемые форматы шрифтов (сейчас в `@font-face` девять начертаний, часть страниц тянет не все);
3. объединить мелкие картинки-иконки в один PNG-спрайт.

Каждый из этих пунктов делается только с отдельным замером до/после.
