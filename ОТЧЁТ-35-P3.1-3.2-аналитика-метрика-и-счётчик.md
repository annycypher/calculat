а не показывает пустые или выдуманные цифры.

## 4. Что нужно от владельца, чтобы цифры Метрики появились

Токен, который есть сейчас, — **только на запись** (его выдавали для создания целей). Для чтения статистики:

1. `oauth.yandex.ru` → приложение `ef35ce34…` → включить право **«Метрика: чтение»**;
2. получить **новый** токен (у старого права не меняются — это проверено на практике в фазе «Цели»);
3. вставить его в панели: **Настройки → «Метрика: чтение статистики»** → «Сохранить токен» → **«Проверить доступ»**.

Кнопка сразу скажет, что доступ есть (и покажет сегодняшние визиты), либо назовёт причину.
Проверка на хостинге уже подтвердила: как только право появится, всё заработает — соединение из PHP сайта проходит.
