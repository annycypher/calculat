ПРОТОКОЛ: Кнопка «Поделиться в MAX» на сайтах CalcDoc
Стратегия: мобильные — нативное меню; десктоп — копирование + web.max.ru
ЗАДАЧА
Добавить кнопку «Поделиться в MAX» в блоки «Поделиться» на страницахсайта calc-doc.ru (инструменты и статьи), реализованную строго постратегии владельца:

Устройство	Решение
Мобильные	Нативное navigator.share уже покрывает MAX (MAX в списке системного меню, если установлен) — ОТДЕЛЬНАЯ КНОПКА НЕ НУЖНА
Десктоп	Кнопка «📤 В MAX» → копирование текста+ссылки в буфер → подсказка «Ссылка скопирована — вставьте в чат MAX» + попытка открыть web.max.ru в новой вкладке
ВАЖНЫЕ ОГРАНИЧЕНИЯ И ПРАВДА О ТЕХНОЛОГИИ
MAX НЕ предоставляет публичный share-URL (вида t.me/share илиvk.com/share.php). НЕ выдумывать несуществующий API и не делатьфиктивных вызовов. Единственная честная десктоп-схема — копированиев буфер + открытие web.max.ru.
Кнопка «В MAX» показывается ТОЛЬКО на десктопе (ширина ≥768pxИЛИ не-мобильный User-Agent). На мобильных — скрыта полностью:нативное системное меню «Поделиться» (navigator.share) уже содержитMAX, если приложение установлено у пользователя.
Бренд-иконка MAX: попробовать взять официальный SVG из пресс-китаmax.ru (если доступен владельцу). Если недоступен — нейтральнаяиконка «сообщение» (SVG в стиле сайта) с текстовой подписью «MAX».НЕ рисовать выдуманный логотип.
OG-теги страницы (og:title, og:description, og:image) уже настроены —они обеспечивают красивое превью ссылки при вставке в чат MAX.Проверить их корректность на страницах с кнопкой.
Сайт в закрытом режиме до «ОТКРЫВАЕМ САЙТ»; деплой — по протоколузакрытого режима, по команде владельца.

После КАЖДОГО шага обновляй PROGRESS.md (этап/шаг/статус/файлы/дальше).

Тест после каждой фазы. Существующие страницы и панель не ломать:перед правкой — полное чтение + копия в backups/.
ИСТИНА ПО ДИЗАЙНУ = текущий styles.css (светлая тема). Кнопка — встиле существующих кнопок шаринга (кнопка «Поделиться» уже есть настраницах — вписаться в её ряд).
ФАЗЫ
ФАЗА M1. ИНВЕНТАРИЗАЦИЯ ШАРИНГА1.1. Пройди все страницы с кнопкой «Поделиться»: где реализована, каким способом (navigator.share / прямые ссылки ТГ-VK-WA / копирование), какой код кнопки. Список в отчёт.1.2. Определи единый компонент: если шаринг реализован по-разному на разных страницах — предложи унификацию (один JS-функционал share.js, подключаемый везде). Жди одобрения владельца.→ Отчёт → «ДАЛЕЕ».

ФАЗА M2. РЕАЛИЗАЦИЯ КНОПКИ «В MAX»2.1. JS (в общий share.js или инлайн на страницах): Функция shareToMax(title, url): 1) text = title + ' — ' + короткая ссылка 2) navigator.clipboard.writeText(text) 3) window.open('https://max.ru', '_blank', 'noopener') — web-версия мессенджера; если popup заблокирован браузером — НЕ ошибка: тост уже показан, пользователь откроет сам 4) тост «Ссылка скопирована — вставьте в чат MAX» (3 сек) Функция isDesktopShare(): показывать кнопку только если matchMedia('(min-width: 768px)') ИЛИ детект не-мобильного UA. На мобильных кнопка скрыта (display:none) — нативное меню navigator.share уже содержит MAX.2.2. HTML кнопки (в ряд существующих кнопок шаринга): [SVG-иконка MAX или нейтральная] В MAX Тултип: «Скопируем текст и ссылку — вставьте в чат MAX».2.3. Вставка кнопки на ВСЕ страницы с блоком «Поделиться» (статьи, инструменты, сценарные страницы) — партиями ≤5 файлов за шаг.2.4. Мобильная логика: на ширине <768px кнопка скрыта; вместо неё на мобильных уже работает navigator.share — ПРОВЕРИТЬ, что он вызывается (не заменён на десктопное копирование). Если на мобильных сейчас стоит копирование вместо navigator.share — ИСПРАВИТЬ (это и есть покрытие MAX на телефонах).Тесты: а) Десктоп: клик → буфер содержит «Заголовок — ссылка», web.max.ru открылся в новой вкладке, тост показан б) Блокировка popup (настройки браузера) → нет ошибки в консоли, тост показан, пользователь может вставить сам в) Мобильная ширина: кнопка «В MAX» отсутствует; нативное меню содержит MAX (при установленном приложении) г) Все страницы с шарингом: кнопка в ряду, не ломает вёрстку на 360px→ Отчёт по каждой странице-партии → «ДАЛЕЕ».

ФАЗА M3. ПРОВЕРКА ПРЕВЬЮ В MAX3.1. Вставка ссылки в чат MAX (владелец делает вручную): убедиться, что превью подтягивается по OG-тегам (og:title, og:description, og:image — светлая обложка с тёмным текстом).3.2. Если превью не подтягивается: проверить og-теги страницы (валидатор), зафиксировать поведение в отчёте — превью в MAX может не рендериться для внешних сайтов (особенность платформы), это НЕ баг сайта; ссылка в чате всё равно кликабельна.→ Отчёт → «ДАЛЕЕ».
