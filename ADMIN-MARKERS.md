# ADMIN-MARKERS.md — куда админ-панель будет писать содержимое страниц

Это результат **шага 0.2** протокола v4 (`PROMPT-ADMIN-V4.md`). Документ отвечает на один вопрос:
куда именно панель будет вставлять свои блоки в существующих 51 страницу сайта.

**Ни одна страница пока не менялась** — это предложение, оно ждёт вашего одобрения.

## Главное правило

Маркеры — обычные HTML-комментарии: посетитель их не видит, вид страницы не меняется ни на букву.

```html
<!--EDIT:seo-->   … текущий SEO-текст страницы …   <!--/EDIT:seo-->   ← панель заменяет содержимое
<!--SLOT:ads-top-->                                                   ← панель вписывает блок
```

* внутри `<!--EDIT:…-->` лежит **тот самый текст, что на странице сейчас**: он остаётся как есть, пока вы не измените его в панели;
* пустой `<!--SLOT:…-->` не рисует ничего — если слот не заполнен, страница выглядит ровно как сегодня;
* вставляются только комментарии, поэтому поисковики и валидаторы видят ту же страницу.
