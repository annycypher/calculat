Сайт не публиковать. Локальная разработка + инструкции.
Безопасность та же: bcrypt, CSRF, htmlspecialchars, валидация путей,сессии. Резервная копия файла перед записью в backups/.
Стиль панели не менять: тёмная тема, русские подписи, подсказки.

S4. СЕКРЕТНОЕ ИМЯ ПАПКИ — проверка и смена: - В security.php блок «Путь панели»: показывает текущее имя папки, статус «нестандартное ✓». Если имя дефолтное-словарное (admin, panel, adm) — красное предупреждение. - Кнопка «Переименовать панель»: ввод нового имени (латиница, цифры, дефис; ≥6 символов) → бэкап robots.txt → скрипт переименовывает папку (rename), обновляет путь в config.php, правит robots.txt → выводит НОВЫЙ адрес входа крупно + просьбу записать его. Двойное подтверждение. Предупреждение: «после переименования зайдите по новому адресу». Тест: переименовать → вход по новому адресу работает, по старому — 404, robots обновлён.
