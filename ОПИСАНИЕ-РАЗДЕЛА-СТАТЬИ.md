# Раздел «Статьи» в админ-панели CalcDoc — механика и устройство

> Полное описание того, как устроен блог сайта изнутри панели: где хранятся черновики, из чего
> состоит редактор, какие есть блоки, как проходит публикация и какие дополнительные возможности
> прилагаются. Документ дополняет короткую сводку в `ПАНЕЛЬ-ПО-РАЗДЕЛАМ.md` (раздел «Статьи») —
> там «что это», здесь «как это устроено».

---

## 1. Место раздела в панели

Раздел «Статьи» — это **блог сайта** `/blog/`. Статья до публикации живёт только в панели как
**черновик**; на сайте она появляется лишь после публикации, когда панель физически записывает
файл `/blog/{адрес}/index.html`.

Ключевые файлы (в `admin-panel-x7k2/`):

| Файл | Роль |
|---|---|
| `articles.php` | главный экран: список статей + редактор + публикация/удаление/корзина |
| `article-template.php` | отдельный «Шаблон статьи»: предпросмотр внешнего вида будущей статьи |
| `inc/articles.php` | движок черновиков: хранение, чистка полей, статусы, корзина |
| `inc/article-template.php` | движок рендера: собирает готовый HTML статьи |
| `inc/publish.php` | публикация/снятие: страница, список на `/blog/`, sitemap, RSS |
| `inc/article-import.php` | импорт готового HTML в блоки редактора |
| `inc/media.php` | библиотека картинок (обложки и картинки в тексте) |

---

## 2. Хранение черновиков

Все черновики лежат в одном файле `content/articles.json` (папка `content/` закрыта `.htaccess`,
в git не попадает):

```json
{ "version": 1, "articles": [
  { "id": "ab12cd34", "status": "draft", "created": "…", "modified": "…",
    "deleted_at": "…", "url": "/blog/…/", "published_at": "…",
    "fields": { …поля статьи… } }
] }
```

**Поля статьи** (их понимает и редактор, и шаблон рендера):

| Поле | Что это |
|---|---|
| `title` | заголовок (H1 и заголовок сниппета) |
| `slug` | адрес `/blog/{slug}/` — латиница, цифры, дефис; пустой собирается из заголовка |
| `seo_title` | заголовок для `<title>`; пусто → «Заголовок — CalcDoc» |
| `description` | описание для поисковика (meta description) |
| `excerpt` | короткое описание для соцсетей (og:description) |
| `keywords` | ключевые слова через запятую (первое — главное) |
| `category` | категория: над текстом и в «хлебных крошках» |
| `breadcrumb` | короткое имя в крошках (пусто → категория/заголовок) |
| `author` | автор в разметке (по умолчанию «CalcDoc») |
| `date_published` / `date_modified` | даты (дата обновления показывается на странице и уходит в разметку) |
| `image` | обложка: карточка на `/blog/`, og:image, превью в соцсетях |
| `intro` | вводный абзац под заголовком |
| `blocks[]` | блоки текста (см. ниже) |
| `faq[]` | вопросы-ответы `{q, a}` → «Частые вопросы» + разметка FAQPage |
| `related[]` | «Смотрите также» `{title, url}` |
| `cta` | строка-призыв перед ссылками |

---

## 3. Список статей

Экран `articles.php` без `?id=` показывает таблицу всех черновиков:

- **поиск** по заголовку, адресу, описанию;
- **фильтр по статусу** — «Все / Черновики / Опубликованные» со счётчиками;
- колонки: заголовок, статус (бейдж «опубликована»/«черновик»), адрес на сайте, **слов в статье**,
  когда изменён (относительное время), действия;
- **действия в строке** зависят от статуса:
  - опубликована: «Редактировать», «На сайте», «Снять с публикации…», «Удалить…»;
  - черновик: «Редактировать», «Предпросмотр», «Опубликовать…», «Удалить…»;
- кнопки сверху: **«Создать статью»**, **«Создать из HTML»** (импорт целой статьи из готового HTML),
  **«Шаблон статьи отдельно»** (переход в `article-template.php`).

## 4. Редактор статьи

Открывается по «Создать статью» (`?new=1`) или «Редактировать» (`?id=…`). Двухколоночная раскладка:
слева основная форма, справа боковая панель с подсказками.

### 4.1. Основное

Заголовок (счётчик 45–60 знаков), заголовок для поисковика `seo_title`, адрес, описание для
поисковика (140–160 знаков), описание для соцсетей, ключевые слова, категория, название в крошках,
даты публикации/обновления, автор и **обложка**.

Обложка:
- выбирается кнопкой **«Выбрать из медиа»** (галерея картинок с размерами, весом и статусом «копии
  под экран»);
- загружается прямо из редактора кнопкой **«Загрузить и поставить обложкой»** (файл уходит в
  `media/uploads`, панель сама сожмёт и сделает копии);
- убирается кнопкой **«Убрать обложку»**;
- если копий под экран нет — кнопка **«Подготовить копии 480/768/1200»**;
- рядом — живое **превью ссылки** (так её увидят в соцсетях/мессенджерах, формат 1200×630).

### 4.2. Блоки текста

Текст статьи набирается **блоками**, идущими по порядку. Доступны 10 типов:

| Тип | Название | Ввод |
|---|---|---|
| `p` | Абзац | textarea; можно `<strong>`, `<em>`, `<a href>` |
| `h2` | Подзаголовок H2 | text |
| `h3` | Подзаголовок H3 | text |
| `ul` | Список | пункты, каждый с новой строки |
| `steps` | Шаги с номерами | пункты; номера ставит сам рендер |
| `formula` | Формула (выделенная строка) | строка |
| `two` | Две колонки (входит/не входит) | заголовки + списки левой/правой колонок |
| `table` | Таблица | строки «ячейка \| ячейка», первая строка — заголовки |
| `image` | Картинка из медиа-файлов | имя файла + alt + подпись + загрузка/выбор |
| `html` | Свой HTML | textarea; опасное вырезается |

Операции над блоками: **добавить** (выбор типа), **↑ выше / ↓ ниже**, **✕ удалить**. Каждое
действие сразу сохраняет черновик.

Вспомогательные удобства:
- **Оглавление блоков** (если блоков больше одного) — липкая панель, клик переносит к нужному блоку;
- **Импорт из готового HTML** (раскрывающийся блок) — заменяет текущие блоки: тот же разбор, что в
  «Создать из HTML» (см. §6);
- **автосохранение**: `Ctrl+S`/`Cmd+S` сохраняет черновик; раз в минуту, если вы не печатали 20
  секунд, черновик сохраняется сам; при уходе с несохранёнными правками — предупреждение.

### 4.3. Картинки в тексте

Блок `image` показывает превью, размеры/вес, статус копий; можно задать `alt` (для незрячих и
поисковиков) и **подпись** (видна на странице). Кнопки: загрузить с компьютера, выбрать из медиа,
подготовить копии. Панель подставляет копии 480/768/1200, размеры и `loading="lazy"` — телефон
получит лёгкую копию, страница не «прыгает».

### 4.4. Частые вопросы

Пары «вопрос/ответ»: добавить, двигать, удалять. Пустые вопросы в статье не появляются.
Попадают и в видимый текст (`<details class="seo-faq">`), и в разметку `FAQPage` — из-за неё в
поиске появляются раскрывающиеся вопросы. Норма 3–5 вопросов.

### 4.5. Смотрите также

Внутренние ссылки `{название, адрес}`: добавить, двигать, удалять. Адрес начинается со `/`
(`/calculators/…` или `/blog/`). Рендерятся блоком «Смотрите также».

### 4.6. Призыв (CTA)

Одна строка-призыв перед ссылками (может быть пустой).

### 4.7. Предпросмотр

Кнопки **«Предпросмотр»** и **«Сохранить и предпросмотр»** собирают страницу тем же шаблоном, что и
публикация, и показывают в рамке; **«Предпросмотр ↗»** открывает собранную страницу в новой вкладке
(`article-template.php?id=…`).

## 5. Боковая панель (подсказки)

- **Статус** — «Черновик» / «Статья опубликована», адрес статьи;
- **Сниппет Яндекса** — как статья выглядит в выдаче: синий заголовок, зелёный адрес, серое
  описание, обрезание длинных строк, подсказки (пустое описание, заголовок >60 знаков, сколько
  вопросов дадут раскрывающийся сниппет);
- **Картинки статьи** — предупреждения: обложка не выбрана / файл не найден / нет копий под экран,
  картинкам в тексте не хватает alt или файла;
- **Замечания** рендера — длина заголовка/описания, число слов, наличие подзаголовков и внутренних
  ссылок;
- **«Предложить связанные статьи»** — подсказки из сканера «Перелинковки»: близкие по теме страницы
  сайта с готовыми «чипами» (готовой ссылкой `<a href>Анкор</a>`, которую вставляют в текст).

## 6. Импорт из HTML

Два входа:
1. **«Создать из HTML»** (`?from_html=1`) — целая статья: заголовок (пусто → берётся из первого
   H2/H3) + HTML-тело → новый черновик.
2. **Блок «Импорт» внутри редактора** — заменяет текущие блоки.

Разбор (`inc/article-import.php`) превращает плоский HTML в блоки:

| HTML | Блок |
|---|---|
| `<h1>` | `h2` (с пометкой «заголовок заполните в поле "Заголовок"») |
| `<h2>` | `h2` |
| `<h3>` | `h3` |
| `<h4–h6>` | `h3` |
| `<p>` | `p` |
| `<ul>` | `ul` |
| `<ol>` | `steps` (если в пунктах есть вложенные блоки — в `ul` с пояснением) |
| `<table>` | `table` (первая строка без `<thead>` считается заголовками) |
| `<img>` | **не переносится** — адрес уходит в отчёт `skipped`, владелец решает сам |
| остальное (blockquote, embed, div, figure, pre…) | `html` |

**Безопасность импорта** (whitelist):
- у inline-текста остаются только `b, strong, i, em, a` (у `a` — только `href`), `code, br`;
- у html-блока вырезаются `style`, `on*`, `class` и целиком `script/style/noscript` (+ iframe/object/
  embed/… внутри абзацев);
- `<script>`, `<iframe>`, `onclick` и т.п. не проходят.

## 7. Публикация

Кнопка «Опубликовать…» → экран подтверждения (что именно будет сделано) → «Да, опубликовать».
Публикуется **сохранённая** версия черновика.

`article_publish()` делает **семь шагов**:

1. чистит поля (пустые блоки/вопросы выбрасываются — на сайт идёт только готовое);
2. собирает страницу шаблоном (`article_render`);
3. записывает `/blog/{slug}/index.html` (перед записью — копия прежнего файла в `backups/files/`);
4. добавляет/обновляет **карточку** статьи в списке `/blog/index.html` (новую — первой в списке);
5. добавляет/обновляет адрес в `sitemap.xml` (`lastmod`, `changefreq=monthly`, `priority=0.6`);
6. пересобирает ленту `/rss.xml` (до 20 карточек);
7. помечает черновик опубликованным (`status=published`, относительный `url`, `published_at`).

Плюс **предупреждения** в отчёте: пустое описание для поисковика, заголовок длиннее 60 знаков.

**Карточка на `/blog/`** (`blog_card_html`): если выбрана обложка — `<span class="card-cover">`
с картинкой, иначе иконка раздела; заголовок, текст (excerpt или description, до 130 знаков),
русская дата и бейдж «Читать →».

### Публикация + заливка на хостинг

Если статья уже опубликована, в редакторе появляются кнопки, совмещающие правку с заливкой:
- **«Сохранить и залить»** (`save_deploy`) — сохраняет правки, обновляет страницу на сайте и заливает
  файлы на хостинг (FTP);
- **«Залить файл»** (`deploy_now`) — заливает только файл этой статьи.

---

## 8. Снятие с публикации

`article_unpublish()`: сначала копия файла страницы → удаление `/blog/{slug}/index.html` → убирает
карточку из `/blog/` → убирает адрес из `sitemap.xml` → пересобирает `rss.xml` → помечает черновик
(`status=draft`, `unpublished_at`). Черновик остаётся в панели — статью можно опубликовать заново.

---

## 9. Корзина (мягкое удаление)

Удаление статьи — **мягкое**: она уезжает в корзину, а не пропадает.

- **В корзину** (`articles_to_trash`): ставит `deleted_at`; если статья была опубликована — сразу
  снимает её с сайта (карточка, sitemap, лента).
- **Восстановить** (`articles_restore`): убирает `deleted_at`; если статья была опубликована —
  возвращает её на сайт.
- **Удалить навсегда** (`articles_purge`): только то, что уже в корзине.
- **Очистить корзину** (`articles_empty_trash`).
- **Автоочистка** (`articles_trash_auto_clean`): статьи, пролежавшие в корзине больше 30 дней,
  удаляются окончательно.

Каждое действие пишется в «Журнал».

## 10. Шаблон статьи (article-template.php)

Страница показывает, как будет выглядеть новая статья **до** создания черновика. Она берёт
**страницу-образец** (по умолчанию `/blog/otpusknye/index.html`), оставляет из неё шапку с меню,
подвал, шрифты и стили, а меняет только заголовок, описание, разметку и текст. Заголовок, категорию,
описание, ключевые слова и адрес можно менять прямо на этой странице и смотреть результат кнопкой
«Показать по-новому».

Режимы:
- `?preview=1` — отдаёт собранную страницу без оболочки панели (её показывает рамка предпросмотра);
- `?id=<id>` — предпросмотр сохранённого черновика (та же сборка, что при публикации, с плашкой);
- на странице есть «Проверка перед публикацией» (замечания без баллов) и «Готовый HTML статьи»
  (кнопка «Скопировать HTML»).

## 11. Движок рендера (inc/article-template.php)

`article_shell()` разбирает страницу-образец на части: `<head>`-ассеты (манифест, шрифты, стили),
шапку `<header>`, подвал/хвост, `site_url`, режим `robots` (пока сайт закрыт — `noindex`, как у всех
страниц) и версию скрипта отзывов. Если образца нет — берётся первая статья из `/blog/`.

`article_render()` собирает полную страницу:
- `<title>` (из `seo_title`, иначе «Заголовок — CalcDoc»), meta description, canonical;
- **JSON-LD** — `Article` и `FAQPage` (если есть вопросы);
- **og-теги** (заголовок, описание, картинка-обложка);
- тело (`article_body`): крошки «Главная / Статьи / …», H1, «Обновлено: …», обложка-герой
  (`post-cover`), рекламные слоты (`SLOT:banner-*`, `SLOT:ads-*`), категория, вступление, блоки
  (слот «после инструмента» ставится на трети текста), «Частые вопросы», CTA, «Смотрите также»,
  примечание «Расчёты носят справочный характер…», блок отзывов.

**Безопасность вывода**: inline-текст пропускает только `b/strong/i/em/a/code/br`; блок `html`
фильтруется DOM-ом (вырезаются `style`, `on*`, `class`, `script/iframe/object/embed`).

---

## 12. Безопасность и права

- Вход обязателен (`require_login`); действия защищены CSRF (`csrf_check`, `csrf_field`).
- Раздел «Мета-теги» / «Массовая мета» дополнительно требуют право `meta`.
- `content/` и `inc/` закрыты `.htaccess`; прямой заход в `inc/*.php` отдаёт 404.
- Импорт HTML и вывод html-блоков работают по whitelist (см. §6, §11).
- Медиа-загрузка проверяет содержимое файла (JPG/PNG/WebP/GIF до 5 МБ).

---

## 13. Связанные разделы

- **Медиа-файлы** (`media.php`) — общая библиотека картинок, откуда берутся обложки и картинки в
  тексте: загрузка (до 5 МБ), сжатие до 1920 px, копии 480/768/1200 в WebP, готовый сниппет
  (`srcset` + `sizes` + `loading="lazy"`), удаление с предупреждением, если картинка используется.
- **Мета-теги** (`meta.php`) — правка title/description/H1 любой страницы (в т.ч. статьи) с
  предпросмотром сниппета и проверкой дублей; меняется только мета, тело байт-в-байт.
- **Массовая мета** (`meta-bulk.php`) — один шаблон заголовка (`[Название]`, `[H1]`, `[Адрес]`) сразу
  для многих страниц, с предпросмотром «было → стало» и журналом.
- **Перелинковка** (`links.php`) — сканер внутренних ссылок; питает блок «Предложить связанные
  статьи» в редакторе.
- **Публикация** (`publish.php`) — заливка изменённых файлов на хостинг по FTP; сюда статья и её
  правки попадают для отправки на живой сайт.
- **SEO-центр** (`seo-center.php`) — полная оценка страниц (фаза 7); редактор статей показывает
  только короткие подсказки без баллов.

---

## 14. Типичный порядок работы

1. «Создать статью» (или «Создать из HTML» для готового текста).
2. Заполнить «Основное» (заголовок, описание, адрес, обложка) и набрать блоки текста.
3. Добавить 3–5 «Частых вопросов» и «Смотрите также».
4. «Сохранить черновик» → «Предпросмотр» → проверить по боковой панели.
5. «Опубликовать…» — панель запишет страницу, карточку в `/blog/`, sitemap и RSS.
6. В разделе «Публикация» нажать «Опубликовать изменения» — залить файлы на живой сайт.

## 15. Сводка дополнительных возможностей

- 10 типов блоков с добавлением/перемещением/удалением и оглавлением.
