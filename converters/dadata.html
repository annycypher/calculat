DaData-конструктор запросов

Соберите запрос к DaData Suggest API (организация, адрес, банк, ФИО) и скопируйте его для проверки.

🔑 Для реальных запросов DaData нужен API-токен. Прямой вызов из браузера может быть ограничен CORS — тогда используйте готовую curl-команду из сервера или терминала.
Токен хранится только в вашем браузере (localStorage).

Результат

Здесь появится запрос (curl) и ответ API.

Как пользоваться конструктором

Выберите тип подсказок (организация, адрес, банк или ФИО), введите поисковую строку и при необходимости токен DaData. Кнопка «Сформировать запрос» соберёт готовую cURL-команду — её можно запустить в терминале или на сервере.

Как получить токен

  • Зарегистрируйтесь на dadata.ru.
  • Найдите API-ключ в личном кабинете (раздел «Настройки»).
  • Подставьте его в поле «API-токен» — он сохранится только у вас в браузере.

Прямой вызов из браузера может блокироваться CORS — тогда используйте готовую curl-команду или прокси-сервер.

Частые вопросы

Что такое DaData Suggest API?

Это сервис подсказок: по части строки он возвращает полное название организации, адрес или банк в структурированном виде (JSON).

Почему запрос из браузера может не сработать?

DaData обычно не отдаёт CORS-заголовки сторонним сайтам, поэтому браузер может заблокировать ответ. Решение — выполнять запрос с сервера или через прокси.
