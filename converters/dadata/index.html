DaData-конструктор запросов: Suggest API для организаций, адресов и банков

Обновлено: 16 сентября 2026

Конструктор собирает готовый запрос к Suggest API DaData: выбираете тип подсказок, вводите поисковую строку — и получаете тело JSON и команду curl, которую можно сразу выполнить в терминале или на сервере. Поддерживаются подсказки по организациям, адресам, банкам и ФИО.

Страница ничего не отправляет на сервер: токен хранится в localStorage вашего браузера, а запрос собирается как текст. Это удобно для разработчиков и аналитиков, которые настраивают автозаполнение реквизитов.

Инструкция

Как собрать запрос к DaData

1Выберите тип — организация, адрес, банк или ФИО
2Введите строку поиска — название, ИНН, часть адреса или БИК
3Укажите токен — API-ключ из личного кабинета DaData
4Скопируйте curl и выполните запрос в терминале или на сервере

Для организаций можно ограничить выборку по ИНН — тогда сервис вернёт конкретную компанию, а не список похожих названий. Количество подсказок задаётся отдельным полем.

Типы подсказок

Что умеет Suggest API

ТипЧто ищетПрактика
partyОрганизации и ИП по названию или ИННПроверка контрагента, автозаполнение реквизитов в договоре и счёте
addressАдреса по частям строкиНормализация адресов доставки и регистрации
bankБанки по названию, БИК или адресуЗаполнение платёжных реквизитов: БИК и корреспондентский счёт
fioФИО с разбором на частиПодсказки в формах заявок и анкет

Ответ приходит в структурированном виде: значение для показа, полное наименование, ИНН, КПП, адрес и другие поля. Из JSON удобно сразу собирать поля формы — пользователю остаётся выбрать вариант из списка.

Пример запроса

Готовая curl-команда

Так выглядит запрос подсказок по организациям с ограничением по ИНН:

curl -X POST "…/suggest/party" -H "Authorization: Token ВАШ_ТОКЕН" -d "{ \"query\": \"7736…\", \"count\": 5, \"constraints\": [{ \"inn\": \"7736207543\" }] }"

Для адресов, банков и ФИО адрес эндпоинта меняется на address, bank или fio, а ограничения по ИНН используются только для организаций. Обязательные заголовки — Content-Type: application/json, Accept: application/json и Authorization: Token ….

CORS: DaData обычно не отдаёт CORS-заголовки сторонним сайтам, поэтому прямой вызов из браузера может быть заблокирован. Рабочий вариант — выполнять запрос со своего сервера, через прокси или serverless-функцию: там же хранится и секретный ключ.

Безопасность

Как обращаться с токеном

  • API-ключ и секретный ключ — разные вещи. Публичный API-ключ можно использовать в клиентских запросах с ограничениями, а секретный ключ предназначен только для сервера.
  • Не публикуйте токен в открытом коде. В репозиториях и на фронтенде он виден всем: вынесите его в переменные окружения сервера.
  • В конструкторе токен хранится локально — в localStorage вашего браузера, и не отправляется на наш сервер. На публичном компьютере очищайте поле после работы.
  • Учитывайте персональные данные. Подсказки ФИО и адресов — это персональные данные: передавайте их только тому сервису, с которым у вас есть договор, и не храните лишнее.
  • Следите за лимитами. Количество запросов зависит от тарифа DaData: смотрите статистику в личном кабинете, чтобы подсказки не перестали работать в самый нужный момент.
Вопросы и ответы

Частые вопросы о DaData Suggest API

Что такое DaData Suggest API?

Это сервис подсказок: по части строки он возвращает структурированные данные — полное наименование организации с ИНН и КПП, разобранный адрес, банк с БИК и корреспондентским счётом или ФИО по частям. Подсказки используют в формах, чтобы пользователь выбирал готовый вариант вместо ручного ввода.

Где взять токен для запросов?

Зарегистрируйтесь на dadata.ru и возьмите API-ключ в личном кабинете — в разделе настроек. Для запросов с сервера подойдёт и секретный ключ, но его нельзя вставлять в клиентский код: он даёт доступ к счёту и лимитам.

Почему запрос из браузера не срабатывает?

Скорее всего дело в CORS: сервис не разрешает вызовы со сторонних сайтов, и браузер блокирует ответ. В этом случае выполните готовую curl-команду на сервере, в терминале или через прокси — конструктор как раз для этого и нужен.

Как найти организацию по ИНН?

В режиме «Организация» укажите ИНН в поле ограничения — оно попадает в запрос как constraints. Тогда подсказка вернёт конкретную компанию, а не список похожих названий: удобно для проверки контрагента и автозаполнения реквизитов в договоре или счёте.

Безопасно ли вводить токен на этой странице?

Токен сохраняется только в localStorage вашего браузера и не отправляется на сервер сайта: страница собирает текст запроса, а не выполняет его у нас. Тем не менее не работайте с ключом на чужом компьютере и не храните секретный ключ в клиентском коде.

Есть ли ограничения по количеству запросов?

Да, лимиты зависят от тарифа DaData: у бесплатного доступа они меньше, платные тарифы расширяют число запросов и набор сервисов. Текущее потребление и остаток лимита видны в личном кабинете — проверяйте их перед нагрузочными тестами и запуском автозаполнения на сайте.

Конструктор формирует только текст запроса: обращения к API выполняете вы, своим токеном и на своих условиях. Перед передачей персональных данных проверьте договор с сервисом и требования 152-ФЗ. Данные не покидают ваше устройство.
